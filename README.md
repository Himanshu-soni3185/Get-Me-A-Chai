# ☕ Get-Me-A Chai

Support creators, one chai at a time.

## 🚀 Overview
Get-Me-A Chai is a full-stack web application built with Next.js that allows users to support creators by sending small contributions (“chai”) along with messages. It provides a simple and modern platform for creators to receive appreciation from their audience.

---

## ✨ Features
- 💳 Send support (“chai”) to creators  
- 🧑 User authentication (if implemented)  
- 💬 Add messages with contributions  
- ⚡ Fast and responsive UI  
- 🌐 Server-side rendering with Next.js  
- 🔐 Secure environment variables  

---

## 🛠️ Tech Stack
- **Frontend:** Next.js, React  
- **Backend:** Next.js API Routes  
- **Database:** (MongoDB / Supabase / etc.)  
- **Deployment:** Vercel  

---
## How to run
**Commands :**
- **to install packages :**
```
npm i
```
 - **to start server :**
```

npm run dev
```
